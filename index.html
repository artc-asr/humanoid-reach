How reach is judged. Neither vendor publishes shoulder torque, so the tool uses the rated payload as a torque proxy: τ = payload × g × arm reach. The furthest the arm can hold this container horizontally is r = τ ÷ (weight × g). Arm self-weight is already inside the payload rating, so r is slightly optimistic once it drops below full reach. Stack height uses the arm held horizontal at full torso lift.
